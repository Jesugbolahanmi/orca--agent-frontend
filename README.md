# Publish your website

No public environment variables are required. ORCAGENT reads the public AQUA Family launch directory directly in the browser.

1. In Studio, connect GitHub and export the frontend. Choose Public for the simplest GitHub Pages setup.
2. Go to the new repository → Settings → Pages → Source and choose GitHub Actions.
3. Go to Actions → Publish website → Run workflow.
4. Open the website link when publishing finishes.

## Local or ZIP setup

1. Serve this directory using a static web server.
2. Open the local site in a browser with internet access.
